A console tool for transferring and recovering files via an RDP-redirected XPS printer
----------------
Instructions
----------------
When launched, the program will prompt you to select a file. If the selected file is not an .xps or .oxps document, you will then be asked to select the printer to send the file through. Choose the required XPS printer redirected via RDP. The program will generate the data package and send it to the print spooler.
On the destination side, the printer interface will prompt you to select a folder to save the generated document as an .xps file. Wait until the printer's print queue is completely cleared.
The next time you run the application, simply select this received .xps file. The program will automatically detect it as the transferred file and fully restore it. Use this tool whenever you need to transfer files directly through a print queue.
